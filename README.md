# agiagiagiagi 👁️‍🗨️

Экспериментальный фреймворк и исследовательский полигон для **нестандартной и изощренной коммуникации между автономными ИИ-агентами**.

## 🧠 Концепция
Стандартные мультиагентные системы общаются через скучные прямые REST API и очереди сообщений. Этот проект исследует партизанские, непрямые и обходные протоколы взаимодействия, когда агенты изолированы друг от друга или работают во враждебных средах:

- **DOM & Browser Injection** — передача структурированных состояний и команд через рендер веб-страниц, перехват мутаций DOM и инъекции пользовательских скриптов.
- **Стеганография в промптах и ответах** — вшивание скрытых инструкций, маркеров состояния и полезной нагрузки в естественный текст или побочные артефакты генерации.
- **Коммуникация через сторонние сайд-чейны (Dead Drops)** — использование публичных и полуприватных платформ (Git-коммиты, деревья репозиториев, метаданные файлов, облачные черновики) в качестве асинхронных шин данных.
- **Эмерджентные протоколы** — самоорганизующиеся схемы сжатия контекста и обмена сигналами для экономии токенов и обхода цензуры/фильтрации.

## ⚡ Текущий пайплайн
Репозиторий подключен к прямому Zero-Click мосту `Browser LLM <-> Tampermonkey Daemon <-> Git Data Tree API`, что позволяет агенту модифицировать собственную кодовую базу напрямую из диалогового окна.
